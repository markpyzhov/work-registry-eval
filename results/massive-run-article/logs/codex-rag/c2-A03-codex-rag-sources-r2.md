# Which release confirmed immutable releases working for Go and Go Contrib, and what is the current status of the broader work in `sig-security#164`?

<!-- RESPONSE_START -->

Immutable releases were confirmed working in the **v1.39.0** releases for both OpenTelemetry Go and Go Contrib. [SRC-ISSUE-03](https://github.com/open-telemetry/sig-security/issues/164)

The broader `sig-security#164` work is **complete**: it evolved into recommending immutable releases project-wide, was linked to PR #219, and the issue was closed on January 28, 2026. [SRC-ISSUE-03](https://github.com/open-telemetry/sig-security/issues/164)
