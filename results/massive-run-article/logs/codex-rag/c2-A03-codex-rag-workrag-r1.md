# Which release confirmed immutable releases working for Go and Go Contrib, and what is the current status of the broader work in `sig-security#164`?

<!-- RESPONSE_START -->

The confirming release was **v1.39.0** for both `opentelemetry-go` and `opentelemetry-go-contrib`. *(SRC-ISSUE-03, `sig-security#164`)*

The broader `sig-security#164` work is **in progress overall, with immutable/signature-release enablement deferred—not done**. Although the GitHub issue was closed on 2026-01-28, release tooling and the order of asset uploads still need to be confirmed safe before enablement is treated as complete. *(WS-03 Security and Fuzzing; SRC-ISSUE-03; CMT-2026-03-003)*
