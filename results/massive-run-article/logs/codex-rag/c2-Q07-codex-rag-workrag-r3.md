# What did the Go SIG decide about the OTelConf RC support PR that was blocking the next release?

<!-- RESPONSE_START -->

The Go SIG decided to merge the OTelConf RC-support PR as-is, subject only to normal review. They deferred review of the experimental API layout—such as using an `x` submodule—to the `1.40.0` milestone, with Alex Boten to open a tracking issue. The release remained blocked pending those PR reviews; the dataset does not establish that the PR was ultimately merged. *(WS-04 Release Process; SRC-NOTE-07)*
