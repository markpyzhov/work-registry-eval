# What did the Go SIG decide about the OTelConf RC support PR that was blocking the next release?

<!-- RESPONSE_START -->

The Go SIG decided to merge the OTelConf RC support PR as-is, subject to normal review. They deferred the experimental-API structure discussion (such as an `x` submodule) to the `1.40.0` milestone, so it would not hold up the release. [SRC-NOTE-07](https://github.com/open-telemetry/opentelemetry-go/issues/6648#issuecomment-3581463689)
