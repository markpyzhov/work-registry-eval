# What did the Go SIG decide to do with Nico’s large runtime-tracer / profiling public-API proposal?

<!-- RESPONSE_START -->

The Go SIG deferred Nico’s large public-API proposal: do not merge it before an issue-based discussion. Keep the existing PR as a draft/proof of concept, document the profiling design and trade-offs in an issue, and first pursue a small change to let users disable runtime-tracer integration.
