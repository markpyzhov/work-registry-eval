# What did the Go SIG decide to do with Nico’s large runtime-tracer / profiling public-API proposal?

<!-- RESPONSE_START -->

The Go SIG deferred Nico’s large public-API proposal. They decided not to merge it until the design had first been discussed in an issue; the existing PR should remain a draft/proof of concept. Nico was to document the problem, options, and trade-offs, then pursue a smaller initial PR to let users disable runtime-tracer integration. The dataset does not establish that either follow-up was filed. *(WS-04 Release Process; SRC-NOTE-08)*
