# Did the OTelConf RC support PR that the SIG agreed to merge actually ship in a release?

<!-- RESPONSE_START -->

Yes. The SIG approved the OTelConf RC-support PR on November 20; the linked OTelConf issue was closed on December 4, and the next release—published December 8—explicitly included a `v0.0.14` module release alongside Go `v1.39.0`. That is the OTelConf RC shipment.
