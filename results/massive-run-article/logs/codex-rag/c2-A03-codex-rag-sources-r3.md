# Which release confirmed immutable releases working for Go and Go Contrib, and what is the current status of the broader work in `sig-security#164`?

<!-- RESPONSE_START -->

Immutable releases were confirmed working with the **v1.39.0** releases for both OpenTelemetry Go and Go Contrib on December 11, 2025.

The broader `sig-security#164` work is **complete**: the issue was renamed to “Recommend immutable releases,” cross-referenced with the recommendation PR, and **closed on January 28, 2026**. [SRC-ISSUE-03](https://github.com/open-telemetry/sig-security/issues/164)
