# Which release confirmed immutable releases working for Go and Go Contrib, and what is the current status of the broader work in `sig-security#164`?

<!-- RESPONSE_START -->

Immutable releases were confirmed working in the **v1.39.0** release for both OpenTelemetry Go and Go Contrib. [Issue #164](../opentelemetry/issues/sig-security-164.md) records that confirmation on 2025-12-11.

The broader `sig-security#164` work is currently **deferred, not done**. Although the GitHub issue was closed on 2026-01-28, the authoritative work state says enablement must wait for confirmation that release tooling and the asset-upload order are safe; the issue has not been reopened. [WS-03](../work-states/WS-03-security-fuzzing.md), [applied correction](../work-states/comments/2026-03.md)
