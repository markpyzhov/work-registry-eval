# What did the Go SIG decide to do with Nico’s large runtime-tracer / profiling public-API proposal?

<!-- RESPONSE_START -->

The Go SIG deferred Nico’s large public runtime-tracer/`pprof` API change: it should not be merged before an issue-based discussion. They decided to keep the existing PR as a draft/proof of concept, have Nico file an issue spelling out the problem, modes/semantics, alternatives, trade-offs, and Go runtime/`pprof` context, and first submit a smaller PR to let users disable runtime-tracer integration. The follow-up issue and smaller PR were not established in the corpus.
