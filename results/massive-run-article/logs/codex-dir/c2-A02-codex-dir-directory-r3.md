# On what date will otelgrpc module stabilization be complete?

<!-- RESPONSE_START -->

No completion date is established. The plan was **not to stabilize otelgrpc in 2025**; it might be prioritized in **2026** if community involvement or additional developer help materializes. The 2025-10-30 SIG meeting instead set a goal to finalize a strategy in 2026, contingent on RPC semantic-convention stabilization and gRPC engagement. As of the 2026-03-08 work-state update, timing remained unresolved.
