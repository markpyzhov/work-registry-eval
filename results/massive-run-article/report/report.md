# massive-run-article analysis report

Generated by `generate_report.py` from `score-cards.csv` (570 scored sessions). Bootstrap CIs use seed 20260724.

Design: 30 questions across 2 corpora (C1 synthetic CipherDoc project, C2 real OpenTelemetry sources), 3 retrieval arms, 2 models, and 3 rounds. Each session was graded by 3 independent scorers (Claude, Codex, Cursor). The final grade is the scorer median, except 75 sessions superseded by human review. Stats are pooled and split by corpus.

Scorer agreement: all three scorers agreed on correctness in 495/570 sessions (86.8%); 6 sessions had full spread (one scorer correct, another incorrect). Scorer agreement describes the raw scorer judgments.
